05 — 07

Motion, GSAP & Smooth Scrolling

Premium websites often feel impressive because of motion, not simply because they contain 3D. When typography, camera movement, and scroll progress synchronize seamlessly, the experience becomes unforgettable.

Stage 4 · Motion

Motion Principles

Great animations feel natural, physics-based, and intentional.

  • • Easing: power2.out, custom cubic beziers
  • • Timelines: sequencing animations gracefully
  • • Stagger: dynamic delayed reveals on lists
  • • Parallax: depth layers moving at different speeds
  • • Scroll triggers: in-view reveals & pinned sections
  • • Micro-interactions: buttons, magnetic cursors
06 · Animation Standard

GSAP + ScrollTrigger

The gold standard tool for award-winning interactive websites.

gsap.to(mesh.rotation, {
  y: Math.PI * 2,
  scrollTrigger: {
    trigger: "#section",
    scrub: 1
  }
});

Practice: text reveals, image wipes, pinned camera orbits, and horizontal scrollers.

07 · Mental Model

Smooth Scrolling Pipeline

Connecting normalized scroll position to 3D world parameters.

Scroll position (0 → 1)
↓
Animation Progress / Scrub
↓
Camera / Mesh / Light Changes

Tools: Lenis, Locomotive Scroll, or GSAP ScrollSmoother.

11 — 12

React Three Fiber (R3F) & Drei

React Three Fiber is a React renderer for Three.js. It lets you build 3D scenes declaratively with reusable components, automatic cleanup, and seamless React state integration.

11 · React Three Fiber pmndrs/fiber

Declarative 3D with R3F

Every Three.js class maps directly to a JSX element with lowercase names.

<Canvas> Manages scene, camera, renderer, and render loop automatically.
useFrame((state, delta) => {}) Runs on every single animation frame for 60 FPS motion.
useThree() Access the root camera, scene, renderer, and viewport dimensions.
<Suspense fallback={...}> Seamless asynchronous loading for models, textures, and HDRI.
12 · Drei Superpowers pmndrs/drei

Essential Drei Helpers

Production-ready building blocks so you never re-invent the wheel.

<OrbitControls /> Effortless camera pan & zoom
<Environment /> HDRI lighting in 1 line
<Float /> Weightless organic floating
<Html /> Anchor HTML DOM inside 3D
<ContactShadows /> Cheap soft ground shadows
useGLTF(url) Auto-cached GLTF/GLB loader
13 — 15

3D Asset Creation: Blender, GLB & Spline

You do not need to become a professional 3D character sculptor. You just need enough Blender skills to clean up meshes, optimize polygon count, bake materials, and export web-ready assets.

13 · Blender Desktop DCC

Learn Just Enough Blender

  • • Navigation & Transformations: G (grab), R (rotate), S (scale)
  • • Decimate Modifier: slashing polycount by 80% without losing silhouette
  • • Texture Baking: baking procedural nodes into 1K/2K diffuse + roughness maps
  • • Origin points: center pivot for realistic interactive rotation
  • • GLTF Export: Draco compression & embed textures
14 · File Formats Web Standards

GLB / GLTF Standards

GLB is the "JPEG of 3D" — binary, compact, and fast to parse on mobile GPUs.

.GLB (Binary): Everything packaged in one file (geometry, animation, textures). Recommended.
.OBJ / .FBX: Legacy formats. Heavy, no web compression. Always convert to GLB using gltf-pipeline.
15 · Spline Browser 3D

Spline for Fast Prototypes

Browser-based 3D design tool built specifically for web designers.

  • • Visual materials, glassmorphism, lighting
  • • Built-in hover, mouse follow, and click events
  • • 1-click export to React (@splinetool/react-spline)
  • • Great for hero illustrations and landing pages
16 — 17

Shaders, GLSL & WebGL Fundamentals

Shaders unlock true creative freedom. Running directly in parallel across millions of GPU cores, they let you create liquid simulations, organic wavy terrains, raymarching, and interactive mouse ripples.

🔮 GLSL Core Mechanics

Vertex Shader

Calculates vertex positions in 3D space. Used for wave distortion, terrain displacement, and vertex morphing.

Fragment (Pixel) Shader

Calculates color for every pixel. Used for liquid gradients, glass refractions, glow effects, and noise patterns.

Uniforms Passed from JS (time, mouse, resolution)
Attributes Per-vertex data (position, normal, uv)
Varyings Passed from vertex to fragment shader
17 · Graphics Pipeline

How Pixels Reach the Screen

You do not need to become a raw graphics engine architect, but understanding this flow clarifies performance bottlenecks:

1 JavaScript / React logic
2 Three.js scene graph & matrices
3 WebGL API binds buffers & shaders
4 GPU rasterization & pixel shading
5 Rendered Frame Buffer on Screen (60 FPS)
Tip: Minimize draw calls by merging static geometries and using instance rendering (<Instances>).

  • ✨ Restraint: 3D serves the product story

19 · Deconstruction

How to Study Great Websites

Inspect Awwwards winners with these 6 analytical questions:

  • 1. What is moving and what is anchored?
  • 2. Is the camera moving or the mesh rotating?
  • 3. What triggers motion: scroll, mouse, or timer?
  • 4. How are textures loaded without lag?
  • 5. How does the mobile fallback look?
21 · Optimization

Performance & Mobile Budget

A slow 3D site is an abandoned site. Enforce these budgets:

  • • Keep models under 50k polygons
  • • Compress textures with WebP or KTX2
  • • Clamp pixel ratio: Math.min(devicePixelRatio, 2)
  • • Disable expensive post-processing on mobile

22 — Beginner Pitfalls & Fixes

❌ Trying to learn everything first

Better approach: Learn enough to build a simple cube, then learn what the project demands.

❌ Starting directly with raw GLSL shaders

Better approach: Master Three.js materials (MeshStandardMaterial) before custom GLSL.

❌ Making every single element 3D

Better approach: Use 3D where it enhances storytelling; keep UI text and navigation in accessible HTML/CSS.

❌ Only watching video tutorials

Better approach: Spend 80% time building, breaking, and debugging projects in code.
